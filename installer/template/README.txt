VISTAAR FOR LG TVs - INSTALLER (Windows)
=========================================
Works with LG TVs from 2020 or newer (webOS 5+). Nothing needs to be installed on your computer.

ON THE TV (once)
 1. Install the app "Developer Mode" from the LG Content Store and sign in with a free LG developer account
    (https://webostv.developer.lge.com).
 2. Switch "Dev Mode Status" ON (the TV restarts), open the app again, switch "Key Server" ON.
 3. Leave "Clear Cache Data" OFF. Note the IP address and the 6-character passphrase on the screen.

ON THIS COMPUTER
 4. Unzip this folder anywhere. Double-click "Install Vistaar.bat".
 5. Type the TV's IP address and the passphrase when asked. Wait for "Done!".

LATER
 - "Extend Developer Mode.bat": run it every few weeks so the app is not removed (max 1000 hours per extension).
 - "Remove Vistaar.bat": uninstalls the app.
 - To update Vistaar, run "Install Vistaar.bat" again with the newer version of this folder.

The computer and the TV must be on the same Wi-Fi/network. Turn off any VPN.
Vistaar is an unofficial client: sign in only with your own Jio account.
